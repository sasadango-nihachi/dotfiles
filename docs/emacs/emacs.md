# emacsについて


自分で割り当てたキー（treemacs / magit / ターミナル等）は [init_config.md](./init_config.md) の「キーバインド一覧」を参照。こちらは Emacs 標準のキー。

# 全体の移動
- C-v（Crtl ＋ v）で画面が下に移動する
- M-v（option + v）でもどるみたい
    - Escを押してからvでも同じことができる
    - Escもメタキーなのか
- C-lでカーソル位置の文字が画面の真ん中に移動した。
    - もう一度押すと上、もう一度押すと下に文字の位置が移動する

※MetaはWindowsではAlt,MacではOptionに該当、SuperはMacではcommandでwindowsには存在しない

# カーソルの移動
- 下記はM-wでコピペできた
                               前の行，C-p

# 基本操作リファレンス

以下は Emacs 30.2 の実機で `key-binding` を引いて確認した割り当て。

## キーの読み方

| 表記 | キー（macOS） |
|---|---|
| `C-` | control |
| `M-` | option（`ESC` を単独で押してからでも同じ） |
| `S-` | shift |
| `s-` | command |

**同時押しではなく順番に押す。** `C-x C-f` は「control を押したまま `x` → `f`」でも、「control+x を押して離す → control+f」でもよい。`C-x b` は「control+x → 離す → `b`」。

`C-x` と `C-c` は**プレフィックス**（それ単体では何もせず、次のキーとの組で1コマンドになる）。

## まず覚える3つ

| キー | 動作 |
|---|---|
| **`C-g`** | **中止**。打ち間違えた・変な状態になった時はこれ。迷ったら連打してよい |
| `C-x C-s` | 保存（`save-buffer`） |
| `C-x C-c` | Emacs を終了（`save-buffers-kill-terminal`） |

`C-g` を知っているかどうかで詰まり方が変わる。

## 用語

| 語 | 意味 |
|---|---|
| **バッファ** | 編集対象の中身。ファイルとは限らない（シェル・Git・ヘルプもバッファ） |
| **ウィンドウ** | 画面の分割区画。**OS のウィンドウではない** |
| **フレーム** | OS で言うウィンドウ |
| **ポイント** | カーソル位置 |
| **マーク** | 選択範囲のもう一端 |
| **ミニバッファ** | 画面最下端の入力欄 |
| **キルリング** | 切り取り履歴（クリップボードの履歴版） |

## ファイル

| キー | 動作 |
|---|---|
| `C-x C-f` | ファイルを開く（`find-file`）。無ければ新規作成。**`TAB` で補完** |
| `C-x C-s` | 保存 |
| `C-x s` | 変更のあるバッファをまとめて保存 |
| `C-x C-w` | 別名で保存 |

## バッファ

| キー | 動作 |
|---|---|
| `C-x b` | バッファを切り替え（`TAB` で補完、直前のバッファが既定） |
| `C-x C-b` | バッファ一覧 |
| `C-x k` | バッファを閉じる |

## ウィンドウ（画面分割）

| キー | 動作 |
|---|---|
| `C-x 2` / `C-x 3` | 上下 / 左右に分割 |
| `C-x 0` / `C-x 1` | 今のを閉じる / 他を全部閉じる |
| `C-x o` | 次のウィンドウへ（順送り） |

## 移動

| キー | 動作 |
|---|---|
| `C-a` / `C-e` | 行頭 / 行末 |
| `M-<` / `M->` | バッファの先頭 / 末尾 |
| `C-v` / `M-v` | 1画面ぶん下 / 上 |
| `M-f` / `M-b` | 単語単位で前 / 後 |
| `M-g g` | 指定行へジャンプ（`goto-line`） |
| `C-l` | カーソル行を画面中央へ。押すたびに 中央→上→下 と巡る |

## 編集

| キー | 動作 |
|---|---|
| `C-SPC` | 選択開始（マークを置く）。以降カーソルを動かすと範囲になる |
| `C-w` | 切り取り（`kill-region`） |
| `M-w` | コピー（`kill-ring-save`） |
| `C-y` | 貼り付け（`yank`） |
| **`M-y`** | `C-y` の直後に押すと**さらに前にコピーしたものへ遡る**（`yank-pop`） |
| `C-k` | カーソルから行末まで切り取り。行頭で2回押すと行ごと消える |
| `C-x h` | バッファ全体を選択 |
| `C-/`（`C-x u` / `C-_`） | undo。**redo は無く、undo を undo する**（一度別の操作を挟むと戻る方向が反転する） |

## 検索・置換

| キー | 動作 |
|---|---|
| `C-s` | インクリメンタル検索（打つそばから移動）。もう一度 `C-s` で次の候補 |
| `C-r` | 後ろ向きに検索 |
| `RET` | 検索を確定してその場に留まる |
| `C-g` | 検索を中止して元の位置に戻る |
| `M-%` | 置換（`query-replace`）。`y`/`n` で1件ずつ、`!` で残り全部 |
| `C-M-%` | 正規表現で置換 |

## ヘルプ（Emacs は自分自身を説明できる）

| キー | 動作 |
|---|---|
| **`C-h k`** + キー | **そのキーが何をするか**。割り当てを調べる時の基本 |
| `C-h f` + 関数名 | 関数の説明とソースの場所 |
| `C-h v` + 変数名 | 変数の説明と現在値 |
| `C-h m` | **今のモードで使えるキー一覧**。知らないモードに入った時に読む |
| `C-h ?` | ヘルプのヘルプ |

## コマンド実行・その他

| キー | 動作 |
|---|---|
| `M-x` | コマンドを名前で実行。`TAB` で補完 |
| `C-u <数字>` | 次のコマンドの繰り返し回数を指定（`C-u 5 C-n` で5行下へ） |
| `M-:` | elisp の式をその場で評価 |
| `C-x C-e` | カーソル直前の式を評価 |
| `C-x C-+` / `C-x C--` | 文字を大きく / 小さく |

## 覚え方の目安

英単語の頭文字が多い。

`C-f` forward / `C-b` backward / `C-n` next / `C-p` previous / `C-a` ahead(行頭) / `C-e` end / `C-k` kill / `C-y` yank / `C-s` search / `C-v` view(次の画面)

`C-` は文字単位、`M-` は単語・文単位、と粒度が上がる対応もある（`C-f` 文字 / `M-f` 単語、`C-a` 行頭 / `M-<` バッファ先頭）。
